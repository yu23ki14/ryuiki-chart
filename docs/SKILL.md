# 神奈川県環境PDF 構造化ルール (P6)

## 年度の扱い
- 「令和4年度」= 2022年度 = 2022-04-01 〜 2023-03-31
- 文書内に少なくとも4パターンが混在する。すべてパースできること：
  「平成29年度」「H29年度」「令和元年度」「2006(平成18)年度」
- 同一文書内で本文と表の表記が違う（本文は併記、表は略号）ケースが実在する
- 西暦先出し（"2005(平成17)年"）と元号先出し（"平成19(2007)年度"）が
  文書によって逆になる。順序で判定せず、両方を受け付ける

## 単位
- 面積は ha と km2 が混在する。1 km2 = 100 ha で正規化し、元表記は残す
- 生息密度は「頭/km2」に統一されているが、面積は ha で書かれることがある
- 金額は「百万円」「億円」が混在する。円に正規化し、元表記を残す

## 区域名（同一視は禁止。人間が承認した対応表のみ使う）
- シカ関連：保護管理区域 / 生息環境管理エリア / 定着防止区域
- 水源関連：水源保全地域 / 水源の森林エリア / 地域水源林エリア / ダム集水域
- 河川関連：国土交通大臣管理区間 / 国管理区間 / 直轄管理区間
  → 上記は「似ているが別概念かもしれない」ものとして扱う。
    対応表 areas_mapping.yaml に人間が書いた行がある場合のみ名寄せする

## 河川・水域の別称
- 相模川は山梨県内では「桂川」。同一河川として扱うが、出典の表記は残す

## 禁止事項
- 数値を推測で埋めない
- 表をまたいで値を補完しない
- 注記を要約しない（原文引用のみ）
- 合計が合わないときに、内訳を調整して合わせない（fail として報告する）
