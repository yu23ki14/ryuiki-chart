# zone（Ridge to Reef 1–5）の操作的定義（v2）

**これは我々（データ統合作業）が便宜的に定めた操作的な区分であり、公式の行政区分・学術区分ではない。**
要求定義書（`app_description.md` §6）は観測地点に「ゾーン（Ridge to Reef 1–5）」を持たせることを
求めているが、この区分に対応する公開データは存在しない。そのため、標高タイルから機械的に算出できる
地形の指標だけを用いて 1〜5 の値を割り当てている。

v2（`definition_version: 2`、2026-10-10、ADR-0031）は神奈川・奄美大島で**共通の定義**である。番号と名称は
v1 から保つ（3 の名称だけ「丘陵・台地・扇状地」に変えた）。標高 800/400/100m・海岸 2km の絶対閾値はやめた。
定義の正は `registry/place/zone.yaml`（`rule:`・`terrain:`）、判定は `scripts/registry/zone_rule.py`、
設計と計測の全文は `docs/plans/AMAMI_STEP0.md`。

**重要な限界**:
- 分水嶺・尾根線・行政界などの地形学的な厳密な流域構造は考慮していない（地点→流域は別件〔Issue #86〕）。
- 閾値は本作業で仮に置いた値で、水野研等のレビューで確定する必要がある（`app_description.md` の確定度「仮」）。
- `sites.zone` の値は、すべてこの操作的定義に基づくもので、現地調査や専門家によるゾーニングの結果ではない。
- **標高の低い島（奄美大島など）では山地（zone 2）が陸の大半を占め、低地（zone 4）はほとんど現れない。**
  奄美の陸の画素全体の配分は zone 1: 5.7% / 2: 73.3% / 3: 13.2% / 4: 0.2% / 5: 7.6%。これは定義の結果で、
  凡例・名称は地域によらず共通である（`zone.yaml` の `note_ja`、caveat `zone`）。

## 定義

判定の順序（上から。最初に当てはまったもの）:

| zone | 名称 | 条件 |
|---|---|---|
| 5 | 河口・沿岸 | 海岸から2km以内かつ標高10m以下（地形の種類より先に見る） |
| 1 | 山地源流域 | 山地（周囲1kmの起伏量200m以上）で、標高が地域の最高峰の半分以上 |
| 2 | 山地渓流 | 山地で、標高が地域の最高峰の半分未満 |
| 4 | 平野・沖積低地 | 標高100m以下・周囲250mの起伏量30m以下・周囲2kmの最低点から15m以内（山地でも沿岸でもない） |
| 3 | 丘陵・台地・扇状地 | 上のどれでもない場所（山地でも低地でもない） |

標高が取得できなかった地点（海上・湾内で DEM が無効）は zone を付けない（推測しない）。神奈川の対象 290 地点では1件。

地域の最高峰は `registry/region.yaml` の `terrain.summit` に宣言する（`jp-14` 蛭ヶ岳 1673m、`jp-46` 湯湾岳 694m。
DEM の最大から導出しない）。最高峰の半分は、神奈川で約837m以上、奄美で347m以上。

## 指標とパラメータ

指標は `scripts/c68_gsi_dem_terrain.py` が地点の座標ごとに計算し、`data/processed/terrain_points.csv` に置く。
`registry/place/zone.yaml` の `terrain:`（指標の定義）と `rule:`（判定の閾値）が値の正で、`params_digest`
（`terrain:` の sha256 先頭12桁）で c68 を回し直していない状態を検出する。

| 指標 | 意味 | 計算 |
|---|---|---|
| `elevation_m` | 標高 | 地理院 `dem_png`（DEM10B）z14 の座標を含む画素。海・欠測（(128,0,0)）は空 |
| `relief_wide_m` | 周囲1kmの起伏量 | 半径1000mの円内の有効画素の 最高−最低（海の画素は除く） |
| `relief_near_m` | 周囲250mの起伏量 | 同、半径250m |
| `floor_min_m` | 周囲2kmの最低標高 | 半径2000mの円内の有効画素の最低標高（z12 タイルでよい。海の画素は除く） |
| `coast_dist_m` | 海岸線までの距離 | C23 の線への最短距離（緯度の cos で経度を縮めた局所平面） |
| `summit_m` | 地域の最高峰の標高 | `region.yaml: terrain.summit.elevation_m` |

| 閾値 | 値 | 根拠・感度 |
|---|---|---|
| 海岸距離 / 標高（zone 5） | 2000m / 10m | オーナー方針。標高10mの上限で、海に落ちる斜面の中腹は沿岸にならない |
| 山地の起伏量（1km） | 200m | オーナー方針。150/200/250 で神奈川の山地（zone 1+2）は 61/51/39 件 |
| 最高峰の比（1/2 の境） | 0.5 | 0.4/0.5/0.6 で神奈川の zone 1 は 7/4/2 件 |
| 低地の標高上限 | 100m | 沖積低地は海面を基準に堆積した地形。これが無いと箱根カルデラ底（標高約725m）が低地になる |
| 低地の起伏量（250m） | 30m | 500m窓だと台地の縁の崖を拾う |
| 周囲2kmの最低点からの比高 | 15m | 台地（大和17m・相模大野27m）と沖積低地（寒川13m・厚木10m）が分かれる境。最低点の半径を3kmにしても神奈川の zone 4 は124→118件 |

## v1 からの変更点

旧定義（履歴）: 標高 > 800m が 1、400〜800m が 2、100〜400m が 3、100m 以下で海岸2km超が 4、2km以内が 5。
海岸線は `scripts/m01_sites.py` の手描きの折れ線（20点、`COASTLINE_LONLAT`）で、標高は地理院標高APIの値だった。

神奈川の zone 付き地点 290（242座標）の旧→新は、一致 171・変更 119。新しい件数は 1:4 / 2:51 / 3:62 / 4:124 /
5:48 / なし:1（旧は 4/11/56/167/52）。主な変化は 3→2 が45（山間のダム湖・渓流）、4→3 が41（台地・扇状地）、
4→5 が11・5→4 が10（手描き海岸線と C23 の違い。海岸距離の差は中央値0.8km・90%点2.7km）。内訳は
`docs/plans/AMAMI_STEP0.md` §1.4 と ADR-0031。

## 標高と海岸線の取得方法

- **zone の判定に使う標高・起伏・最低点**: 国土地理院の標高タイル `dem_png`（基盤地図情報数値標高モデル
  10mメッシュ）。c68 が z14（約680枚）と z12（約140枚）を1.5秒以上の間隔で取得し、`data/raw/gsi_dem_png/`
  にキャッシュする。タイルそのものは再配布せず、派生値（標高・起伏量）だけを `terrain_points.csv` に持つ。
  国土地理院コンテンツ利用規約（政府標準利用規約2.0互換）に従い出典を表示する。
- **海岸線**: 国土数値情報 海岸線データ C23（`C23-06`、平成18年版。神奈川 597本・奄美5市町村 1,071本）。
  c36 が `data/processed/nlni_c23_coastline.geojson` に作る。許諾は「非商用」で、zone 全体が C23 由来の海岸距離に
  依存する。商用提案では C23 を差し替えるか zone を外す（`docs/LICENSE_MATRIX.md`）。埋立・護岸の変更は入っていない。
- **`sites.elevation_m`（台帳の標高。zone の判定には使わない）**: 気象庁アメダス地点は気象庁が公表している
  観測点の標高値（自己申告値）、それ以外は国土地理院 標高API
  （`https://cyberjapandata2.gsi.go.jp/general/dem/scripts/getelevation.php`）を1地点あたり1.5秒スロットルで
  呼び出して取得。API呼び出し件数の上限は `scripts/m01_sites.py` の `ELEV_CAP`（500件）、結果は
  `data/processed/_elevation_cache.json` にキャッシュする。zone の判定は上のタイルの標高を使うので、
  台帳の `elevation_m` と数m違うことがある。

## 流れ

c36（C23）→ c68（terrain_points.csv）→ m01（台帳。zone は入れない）→ m09（`sites.zone` を v2 に更新）→ r01（`zone` place と
`place_relation` を作る）。m09 の後は `build:registry` を明示する（`docs/PIPELINE.md`）。

## 弱点

標高は10m格子の画素で橋・堤防の標高が入る／1/2 の境は最高峰の宣言値1つに依存する／標高100m超の平坦面は 4 にならない
（箱根カルデラ底は 3）／3/4 の境は成因ではなく起伏と最低点からの比高による代理／海岸の岬・海崖では起伏量が小さめに出る／
C23 は平成18年版。専門家に確かめる点は ADR-0031 の末尾。

## `treatment`（対策区／対照区／参照）との違い

`treatment` は zone とは別の概念であり、公開データには一切存在しないため、実データ由来の
`sites` レコードでは常に NULL のままにしている。合成（デモ用）データを別途生成する場合に限り、
そちらで付与する想定。
