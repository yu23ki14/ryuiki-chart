# ADR-0031: zone（Ridge to Reef 1–5）を地域共通の定義（v2）に差し替える — 起伏量・最高峰の比・C23 海岸線

- 状態: 承認済（2026-10-10 オーナー決定。閾値は水野研等の専門家レビューで確かめる） / 日付: 2026-10-10
- 関連: ADR-0002（複数地域。zone の閾値を地域ごとに持たせる旨を本 ADR が更新）,
  ADR-0004（識別子。規約0・2、日付付きの追記あり）, ADR-0022（place のスコープ。決定1の実測表の
  zone 行は本 ADR で `common` に移った）, ADR-0028（座標の一般化はしない）,
  Issue #89, [docs/plans/AMAMI_STEP0.md](../plans/AMAMI_STEP0.md)（設計・計測の全文）,
  [docs/ZONE_DEFINITION.md](../ZONE_DEFINITION.md)（定義の説明）

## 背景

v1 の zone は標高 800/400/100m と海岸 2km の絶対閾値で、海岸線は手描きの折れ線（20点）だった。
奄美大島（`jp-46`）を足すと破綻する: 最高峰の湯湾岳が 694m で「標高 800m 超」に1点も入らず、
島の幅が狭いので「海岸から 2km 以内」が陸のほぼ全域になる。zone を地域別に定義し直すと、
`place_source_ref(key_space='zone', external_key='1')` が地域ごとに二重になり、キューブの
ゾーン絞り込み（番号の一致）が二重に数える。そこで番号・名称を保ったまま、神奈川・奄美で
**共通の定義**に差し替える。

## 決定

1. **規則**（`definition_version: 2`。`registry/place/zone.yaml` の `rule:` が正、判定は
   `scripts/registry/zone_rule.py` の `classify()`）。入力は座標から c68 が計算する指標
   （`data/processed/terrain_points.csv`）と、地域の最高峰だけ。
   - 5 河口・沿岸: 海岸（C23）から 2km 以内かつ標高 10m 以下（地形の種類より先に見る）。
   - 1/2 山地: 周囲 1km の起伏量が 200m 以上。標高が地域の最高峰の 0.5 倍以上なら 1、未満なら 2。
   - 3/4 それ以外: 標高 100m 以下・周囲 250m の起伏量 30m 以下・周囲 2km の最低標高から 15m 以内の
     3条件を満たせば 4（平野・沖積低地）、そうでなければ 3（丘陵・台地・扇状地。名称は旧「丘陵・扇状地」から変更）。
   - 標高が取れない地点は zone を付けない（推測しない）。
2. **最高峰は宣言値**: `registry/region.yaml` の `terrain.summit`（`jp-14` 蛭ヶ岳 1673m、`jp-46` 湯湾岳 694m）。
   DEM の最大から導出しない。c68 が宣言座標の周辺 500m の DEM 最大が宣言値 ±20m に収まるかを検査する
   （実測: 1672m・692m）。
3. **標高・起伏は国土地理院 `dem_png`（DEM10B）**から c68 が計算する。W12（流域ポリゴン）には依存しない
   （地点→流域は Issue #86 の別件）。
4. **海岸線は国土数値情報 C23**（c36）。神奈川も切り替え、`scripts/m01_sites.py` の手描き
   `COASTLINE_LONLAT` は撤去する。許諾は「非商用」（W05 等と同じ。`docs/LICENSE_MATRIX.md`）。
5. **place のスコープは `common`**: `jp-14:place:zone.r2r.N` → `common:place:zone.r2r.N`（`region_id` は NULL）。
   定義が地域非依存になったので ADR-0004 規約0・ADR-0022 決定1にそのまま当てはまる。同じ実体の ID の改称なので
   `id_map` で扱い `superseded_by` は使わない。**ID に版は入れない**。版は `place.definition_ref` と
   `place_relation.basis` の `definition_version: 2` に残す。ADR-0022 決定1の実測表の zone 行は `common` に移った。
6. **`sites.zone`**（台帳の列）は m0x の流儀で `scripts/m09_site_zone.py` が更新する（旧値は `reports/zone_v2_migration.csv`
   に残す）。ビルド（`build_place`）は台帳の値と `classify()` の一致を検査する。
7. **ADR-0002 の更新**: 「zone の閾値を place のメタデータに地域ごとに持たせる」は採らない。閾値は
   共通の `zone.yaml` 1つで、地域ごとに違うのは最高峰の宣言値だけ。

## 却下した代替案

- **J-SHIS の微地形区分**: 奄美の河口で欠け、再配布もできない。
- **W12 の小流域・水系域を基準にする**: 奄美では面が欠け、水系も1つしかない。
- **zone を地域別に定義する**: 番号が衝突し、キューブの絞り込みが二重に数える（背景）。
- **ID に版を入れる（`r2r2`）**: v1 の zone を参照する外部の引用が無く（v1 の API は撤去済み）、
  ID を変える理由がスコープ移動だけで足りるので採らない。

## 影響

神奈川の zone 付き地点 290（242座標）の旧→新（計測: 2026-10-10、標高タイル z14 が677枚・z12 が約140枚、C23 は平成18年版）:

| 旧＼新 | 1 | 2 | 3 | 4 | 5 | 付かない |
|---|---|---|---|---|---|---|
| 1 | 4 | 0 | 0 | 0 | 0 | 0 |
| 2 | 0 | 5 | 6 | 0 | 0 | 0 |
| 3 | 0 | 45 | 11 | 0 | 0 | 0 |
| 4 | 0 | 1 | 41 | 114 | 11 | 0 |
| 5 | 0 | 0 | 4 | 10 | 37 | 1 |

一致 171、変更 119。新しい件数は 1:4 / 2:51 / 3:62 / 4:124 / 5:48 / なし:1（旧は 4/11/56/167/52）。
主な変化: 3→2 が45（山間のダム湖・渓流）、4→3 が41（台地・扇状地側）、4→5 が11、5→4 が10
（手描き海岸線と C23 の違い）。海岸距離の差は中央値 0.8km・90%点 2.7km。
確認地点は神奈川 30 地点（期待どおり 29。平塚馬入は規則の境界で `known_miss`）と奄美 13 地点（13/13）。
API・MCP・画面・AI の出力は zone の分類結果の変化だけで、形は変わらない（`ZONE_INFO` は番号と名称、
キューブの絞り込みは番号）。

奄美の陸の画素全体（11,131点）の配分は zone 1: 5.7% / 2: 73.3% / 3: 13.2% / 4: 0.2% / 5: 7.6%。
**島では zone 2 が大半を占め、zone 4 はほぼ現れない**。これは定義の結果として受け入れ、`zone.yaml` の
`note_ja` と caveat `zone` に書く。

## 弱点（専門家レビューで確かめる点）

1. 標高は DEM10B の画素で、橋・堤防・盛土の標高が入る。zone 5 の「10m 以下」の境付近が動く。
2. 1/2 の境は最高峰の宣言値1つに依存する（神奈川約837m、奄美347m）。尾根・谷・流域内の位置は見ていない。
3. 標高 100m 超の平坦面を 4 にしないので、箱根カルデラ底（芦ノ湖の湖面）が 3 になる。
4. 3/4 の境は成因ではなく起伏と周囲 2km の最低点からの比高による代理。境ぎりぎりの地点がある。
5. 海の画素は DEM が無効なので岬・海崖で起伏量が小さめに出る。C23 は平成18年版で、その後の埋立は入っていない。
6. 水野研（または地形に詳しい人）に確かめる: (a) 周囲1kmの起伏量200mは奄美の低く急な山でも妥当か、
   (b) 最高峰の半分で 1/2 を分けてよいか、(c) 海岸 2km・10m は奄美のリアス式海岸・サンゴ礁に合うか、
   (d) zone 3 に台地・丘陵・扇状地をまとめてよいか。
