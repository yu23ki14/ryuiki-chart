# 奄美 Step 3b: 2010年奄美豪雨の雨量・被害を行政文書の表に載せる（Issue #89）

京都大学防災研究所の速報と鹿児島大学の報告書（2012年）から、雨量と被害の**数値という事実だけ**を原本 `cells.sqlite` の documents・cells・notes に入れる。出典の食い違いは両論併記にする。雨量の時系列は気象庁の既存データ（名瀬）を使う。2026-10-11 に設計担当が原資料を取得して確かめた。

## 0. 実測で Issue の記述と変わった点

1. **「住用で24時間703mm・1時間131mm」は気象庁の値ではない。** 気象庁のアメダスに住用は無い（奄美の局は名瀬・笠利・古仁屋・喜界島・天城の5つ。`amedastable.json` で確認）。住用は鹿児島県（大島支庁）の住用村観測所の値。気象庁の値で突き合わせられるのは名瀬・古仁屋だけ。
2. **総雨量の食い違いは住用の2点ではなく3点。** 京大 894mm、鹿大の序文 891mm、鹿大の表-2（連続雨量）893mm。名瀬は京大 766mm・鹿大表-2 766.5mm。
3. **鹿大の報告書は「日雨量」の語を2通りに使う。** 表-2 の日雨量（住用703・名瀬648）は24時間雨量（京大の値と一致。第2章の本文も「24時間雨量は名瀬で648mm」）。同じ報告書の別の章の「20日の日雨量」（名瀬622・古仁屋286.5）は暦日で、気象庁の日降水量と一致する。cells の row_key と notes で区別する（§3.3・§4）。
4. **被害の件数も出典と時点で割れる。** 全壊・半壊: 京大 485棟、県の11/26報告 489棟（全壊10＋半壊479）、安達ほか 565棟。床上・床下: 京大 576・736件、県11/26 119・767棟、安達ほか 130・762棟。死者は3名で全部一致。
5. **被害の「表」は表ではない。** 鹿大の被害状況（県11/26報告）は画像の箇条書き（585×266の PNG、文字情報なし）。京大の速報には被害の表が無く、雨量も被害も本文の文章。表の形の文字情報があるのは鹿大の表-2（雨量3地点）だけ。OCR は要らない（画像は小さく、目で読んで合計で検算できる。§5）。
6. **流域治水プロジェクトは既に documents にある**（`bodik_460001_amami_ryuiki_chisui_2022`、Step 2d）。今回は触らない。
