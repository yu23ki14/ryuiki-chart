作業日: 2026-09-05 / 対象: 設計図 Phase 3「横須賀市を 1 事業体まるごと追加する」

## 結論を先に

**設計図 §4 の見立て「有馬系（相模川から自前導水）＋企業団受水（伊勢原・綾瀬・小雀の各系統）＋走水水源地（地下水）」は、
1 点を除いて裏付けられた。覆ったのは走水の種別で、地下水ではなく「市内湧水」。**

**そして最大の収穫は、施設能力比で概算を置く必要が無かったこと。**
横須賀市の水道事業統計年報に **「系統別着水量」の年間実績**があり、5 つの水源系統ごとの実測値が
そのまま取れた（`DOC_YKS_TOUKEI_R6` p31・p32）。当初は水源系統ページの供給可能水量
（＝施設能力）で `basis=nominal` を置くつもりだったが、**実績に置き換えた**。

**割付は市内全域（348 町丁目・388,078 人）。** 給水区域は市全域で、
合成結果は **相模川 98.8% / 酒匂川 0.68% / 走水の湧水 0.50%**。

そこは町丁目の粒度で公表されていないので `basis=estimated` / `confidence=low` にしてある（下記）。

### （新規に判明）1 — 有馬浄水場は 2 つの水源が合流する場所

**設計図は「有馬系（自前）」と「企業団受水（伊勢原）」を別々の系統として書いているが、
実際には企業団伊勢原浄水場の水は有馬浄水場に入る。**

> 有馬浄水場（海老名市中河内）で、相模大堰からの水を浄水するとともに、神奈川県内広域水道企業団
> 伊勢原浄水場からの水を受け入れ、横須賀市内へ送っています。（`DOC_YKS_KEITO_ARIMA`）

企業団の給水地点「有馬」の所在地（海老名市中河内）は有馬浄水場の住所と一致する
（`DOC_KGD_GAIYOU_R8` p49）。したがって `flow_edge` は

```
SRC_SAGAMI → FAC_YKS_SHAGE（社家導水ポンプ）→ FAC_YKS_ARIMA（有馬浄水場）  share 0.970127
FAC_KGD_ISEHARA（企業団伊勢原浄水場）      → FAC_YKS_ARIMA（有馬浄水場）  share 0.029873
```

とした。**この 2 本は `basis=measured`**（どちらも令和6年度の実績値。18,026,610 ㎥ と 555,030 ㎥）。
なお `DOC_YKS_WEP_R8` p3 の有馬浄水場の「原水の種類」は表流水（相模川）だけで、
企業団の水は**浄水として**受け入れる（原水ではない）。それでも蛇口から出る水の由来としては合流している。

### なぜ配水ブロックに分けなかったか（`confidence=low` の理由）

**分けるべき情報はあるのに、境界が公表されていない。**

`DOC_YKS_WEP_R8` p8 に **5 つの配水ブロック（北・東・中・南・西）の色分け図**があり、
p13 に次の記述がある。

> ①北ブロックは、小雀系統からのみ影響を受ける給水区域と、小雀系統及び宮ケ瀬系統をブレンドした
> （両系統の影響を受ける）田浦第２配水池の給水区域での水質が異なるため、２か所に自動水質監視装置を
> 設置しています。
> ②東ブロックは、走水系統の影響を受ける地域と、ほかの給水区域で水質が異なるため、２か所に…

つまり少なくとも

- **北ブロックは小雀系統と宮ヶ瀬系統だけ**（＝どちらも相模川 100%。酒匂川も走水も来ない）
- **走水系統は東ブロックの一部にしか行かない**

ことが分かっている。それでも分けなかったのは、**p8 の図が「配水ブロック」の図であって
「水源系統」の図ではない**から。川崎市の図−7 のように「この色＝この浄水場系」という凡例が無く、
5 ブロックそれぞれの水源構成は北ブロック以外どこにも書かれていない。
ラスタ読み取りをしても、読めるのは「北ブロックはここ」までで、
残り 4 ブロックの水源が分からないので割付には使えない。

**`confidence` を `low` にし、`FAC_YKS_CITY` の note にこの事情を書いてある。**
配水ブロック別の水源構成が手に入れば、少なくとも北ブロックは「相模川 100%」に上書きできる。

## 判断に迷った点

### 1. 走水の湧水（0.5%）を市全体の構成に入れるか

**入れた。** 資料（`DOC_YKS_WEP_R8` p13）が「走水系統は東ブロックの一部にしか行かない」と明言しているので、
市の大半の住民にとっては 0.5% ではなく 0% が正しい。逆に外すと、走水地区の住民にとって
唯一の地元水源が消える。

決め手は 2 つ。
- **年報の「系統別着水量」に 5 系統が並んでいる**のに、そのうち 1 つだけ落とすのは編集にあたる。
  外した場合は残り 3 系統を 100% に正規化することになり、それはそれで捏造。
- 誤差が **0.5%** と小さく、**最上位水源（＝地図の色）は相模川で変わらない**。
  カードには「走水の湧水 0.5%」と出るが、比率つきで出るのでスケール感は誤解されにくい。

`FAC_YKS_CITY` の note と `E_YKSHASHIRIMIZU_YKSCITY` の note に**「走水系統は市内全域には行かない」**と
明記してある。問い合わせリストの筆頭に置いた。

### 2. 供給可能水量（施設能力）で置くか、着水量（実績）で置くか

最初は水源系統ページの供給可能水量（走水 1,000 / 有馬 73,900 / 小雀 143,300 / 酒匂川 18,600 /
宮ヶ瀬 113,500・計 350,300 ㎥/日）で `basis=nominal` を置くつもりだった。
これだと酒匂川が **3.7%** になる。**実績（年報）に置き換えたら 0.68% になった。**
5 倍違う。伊勢原からの受水枠 18,600 ㎥/日に対して実際の受水が 1,521 ㎥/日（1 日平均）しか無いため。

**実績を採った。** 施設能力は「最大どれだけ取れるか」であって「実際に飲んでいる水がどこから来たか」ではない。
`docs/add_utility.md` §2 も `nominal`（施設能力比の概算）より上の段に実績を置いている。

### 3. 小雀浄水場を新しい施設として作るか

**作らなかった**（既存の `FAC_YOK_KOSUZUME` を使った）。
横浜市水道局との共同施設で、横須賀市分（1 日 217,800 ㎥）も同じ施設・同じ原水（寒川取水堰の相模川）で作る。
`FAC_KEN_SAMUKAWA_JP`（県営の寒川浄水場）を企業団のものと**分けた**のとは逆の判断だが、基準は同じで
「**原水が同じなら分けない・違うなら分ける**」。寒川は県営と企業団で事業が別（浄水委託）だったのに対し、
小雀は文字どおり 1 つの施設を共同で持っている。

なお企業団の小雀浄水場（給水地点「小雀第2」）も同じ敷地にあり、これも寒川取水堰の相模川。
3 者とも原水が同じなので、まとめても合成結果（相模川 100%）は変わらない。

### 4. 企業団の給水地点「田浦」が逗子市にあること

給水地点「田浦」の所在地は**逗子市沼間**（`DOC_KGD_GAIYOU_R8` p50）。
横須賀市田浦地区に配る水を、市境の外にある受水地点で受けている。
**逗子市に横須賀市が給水しているわけではない**（逗子市は県営水道の給水区域で `R_KEN_ZUSHI` で割付済み）。
末吉配水池が横浜市内にあるのと同じ型の話。混同しないよう `FAC_YKS_CITY` の note と
`E_KGDAYASE_YKSCITY` の note に受水地点名を残してある。
