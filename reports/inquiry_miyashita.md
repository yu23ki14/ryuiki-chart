## いま分かっていること / 分かっていないこと

`DOC_KAN_SUIDOU_R5`（令和5年度 神奈川県の水道）p50・p51 からしか分からない。

| 分かっている | 値 |
|---|---|
| 給水人口 | 4,106 人（計画 5,000 人） |
| 年間給水量 | 611,486 ㎥ |
| 取水の種別と年間取水量 | **地下水（浅井戸＋深井戸）2 箇所 7,705 ㎥ / 湧水・その他 3 箇所 603,781 ㎥** |
| 浄水施設 | 緩速ろ過 2・急速ろ過 3 |
| 給水区域 | 「宮下番地の一部、土肥4・5丁目、土肥1・6丁目の一部」（`DOC_YGW_KUIKI`。湯河原町のページ） |

| 分かっていない |
|---|
| **水源の名称・所在地**（5 か所あるはずだが名前が 1 つも分からない） |
| **湧水の涵養域**（水源名が分からないので追いようがない） |
| 系統ごとの給水区域 |

いまは `SRC_MIYASHITA_SPRING`「宮下地区の湧水」・`SRC_MIYASHITA_GW`「宮下地区の地下水」という
種別だけのノードを置き、比率は県の年間取水量（湧水 98.74% / 地下水 1.26%）で `basis=estimated` にしてある。
**note に「水源名・所在地・涵養域は不明」と明記した。**

## 補足: この情報が無くても地図は出る

宮下簡易水道の 3 町丁目（宮下・土肥四丁目・土肥五丁目／3,516 人）は
「宮下地区の湧水 98.7% / 宮下地区の地下水 1.3%」として地図に出ている
（`palette.ts` では「その他の水源」に束ねられる）。
**水源名が分かれば水源カードの表示が「宮下地区の湧水」から実際の水源名に変わる**、
というのが得られる改善で、割付率は変わらない。優先度は高くない。
